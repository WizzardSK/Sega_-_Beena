# Sega_-_Beena

Thumbnails for Sega Beena software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Snaps`), named after the MAME short names, as the MAME `sega_beena_cart` software list has them.

The snaps were taken with the MAME libretro core in RetroArch: each cartridge is run on its own for 2400 frames (3600 for the slower ones) and the last frame is kept, cropped to the TV picture at 640x480. Without a player the games stay on their title screen, which is what the snaps show. Games that stayed blank have no snap.
